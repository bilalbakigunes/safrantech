# SafranTech Team 8777 Web Sitesi

Bu proje, 11. sınıf Web Tasarım dersi için hazırlanmış çok sayfalı bir tanıtım sitesi örneğidir.

## Dosya Yapısı

- `index.html` — Anasayfa
- `about.html` — Hakkımızda
- `projects.html` — Projelerimiz
- `gallery.html` — Galeri
- `contact.html` — İletişim
- `css/style.css` — Tüm özel stiller
- `js/main.js` — Etkileşimli özellikler
- `assets/` — Logo ve görseller

## Teknik Özellikler

- HTML + CSS + Bootstrap + JavaScript
- Responsive tasarım
- Ortak navbar ve footer
- 5 ayrı sayfa
- İletişim formu
- Galeri modalı
- Proje ve galeri filtreleme
- Proje arama alanı
- Sayaç animasyonu
- Ayrı CSS ve JS dosyaları

## Kullanım

1. `index.html` dosyasını bir tarayıcıda açın.
2. En iyi görünüm için internet bağlantısı önerilir.
   - Bootstrap CDN
   - Google Fonts
   - Google Maps gömülü harita

## Not

Bu proje içeriği, okul ve takım hakkında kamuya açık bilgiler ile kullanıcı tarafından sağlanan görseller temel alınarak düzenlenmiştir.
